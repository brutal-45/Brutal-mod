🎙️ Microphone Output Setup

To play sounds through your microphone in Discord, games, and other apps, you need to install a virtual audio cable.

Download VB-Cable (Free) ↗

📋 How to Setup

  1. Install VB-Cable from the link above
  2. Restart your computer
  3. Set "CABLE Input" as Windows default playback device
  4. Set "CABLE Output" as microphone in Discord/Games
  5. Now BrutalMod sounds will play through your mic!
