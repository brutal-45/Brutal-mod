                      🚀 QUICK START 
════════════════════════════════════════════════════════════════

OPTION A: RUN AS HTML (No installation)
─────────────────────────────────────────
1. Double-click "index.html" to open in browser
2. Add sounds using the "Add Sound" button
3. Assign hotkeys by clicking the hotkey button
4. Start playing sounds!

OPTION B: BUILD AS .EXE (Windows App)
─────────────────────────────────────────
1. Install Node.js from https://nodejs.org
2. Run "build.bat" (Windows) or "./build.sh" (Mac/Linux)
3. Find the exe file in the "dist" folder
4. Install and enjoy!

════════════════════════════════════════════════════════════════
                    🎤 MIC OUTPUT SETUP
════════════════════════════════════════════════════════════════

To play sounds through your microphone in voice chats:

1. DOWNLOAD VB-CABLE (FREE)
   → https://vb-audio.com/Cable/
   → Install and restart your PC

2. CONFIGURE WINDOWS AUDIO
   → Right-click speaker icon in taskbar
   → Open Sound Settings
   → Set "CABLE Input" as Default Playback Device

3. CONFIGURE YOUR VOICE APP
   → Discord: Settings → Voice → Input Device → "CABLE Output"
   → Zoom: Settings → Audio → Microphone → "CABLE Output"
   → Teams: Settings → Devices → Microphone → "CABLE Output"

4. DONE!
   → All sounds from BrutalMod will now play through your mic!

                    🎮 USAGE TIPS
════════════════════════════════════════════════════════════════

HOTKEYS
• Click the ⌨ button on any sound to assign a hotkey
• F1-F12 keys work best (no conflicts with typing)
• Escape key stops all sounds

CATEGORIES
• Organize sounds by category
• Click category chips to filter
• Edit sound to change category

VOLUME
• Use master volume for overall control
• Individual volumes for each sound
• Adjust before important calls

DRAG & DROP
• Drag audio files directly into the app
• Supports multiple files at once
• Works with MP3, WAV, OGG, M4A, FLAC

                    ❓ TROUBLESHOOTING
════════════════════════════════════════════════════════════════

Q: Sounds don't play through my mic
A: Make sure VB-Cable is installed correctly:
   • System playback = CABLE Input
   • Voice app mic = CABLE Output

Q: No sound at all
A: Check:
   • System volume is up
   • App master volume is up
   • Browser/app has audio permissions

Q: Hotkeys not working
A: • Make sure app window is focused (HTML version)
   • Global hotkeys work anywhere (EXE version)

Q: Build fails
A: • Make sure Node.js is installed
   • Run "npm install" first
   • Try deleting "node_modules" and reinstalling

Q: Sounds disappear after closing
A: • Don't use private/incognito mode
   • App saves to localStorage automatically
   • Use Export feature for backup
